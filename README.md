## Lab Questions
### 1 - How might you add more than two bits together?
you can line up multiple full adders and the carry from each one gets passed to the next adder eventually getting the answer this can be done with an XOR and an AND gate.
### 2 - What is the importance of the XOR gate in an adder?
The XOR gets the sum of 2 bits when the sum is 1
this will allow the AND gate to work for scenarios where the sum is =2

### 3 - What is the largest number a two bit adder can handle? What happens when you go over?
the biggest number is 1, you need to add another bit space for anything bigger.
